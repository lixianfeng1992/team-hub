# Ch 4: grill-me 案例 —— 好 skill 长什么样、为什么能火

## Core Idea
一个小、单用途、手动触发、鼓励改的 skill，用"不教实现只逼需求"的设计成为圈层型爆款。

## Frameworks Introduced
- **圈层型爆款 vs 流量型爆款**：判断标准是分享密度（分享/阅读）
  - 真正干活的人会转给同事；转发本身 = "我在乎流程控制权，我不 vibe coding"
- **数据信号组合**：一个纯 markdown 仓库是否真有价值
  - fork/star 比 8.6%（普通爆款 2%–5%）→ 人们 fork 回去改、回去用，fork 是工作流不是致敬
  - 安装量是 star 的 40 倍 → 直接 npx 消费，star 低估真实规模
  - 大量 open issues（237 个）→ 真有人用、真在迭代

## Key Concepts
- **三波增长**：单品病毒（grill-me 推到 ~9k 星）→ 全仓引爆（反叙事帖 + newsletter + 现场演示）→ 生态红利（第三方清单置顶为 reference implementation）
- **信任储蓄**：六年积累（Total TypeScript 250 万美元营收）让作者的判断有分量
- **商业飞轮**：仓库是 AI Hero 课程漏斗的免费入口，19 万星是获客成本为零的漏斗顶端
- **对立人设**：README 点名当红框架，把自己定位成 vibe coding 的反方

## Mental Models
- 单品负责出圈，元理论负责留人
- 渠道是自己的，发布才是可重复触发的事件

## Anti-patterns
- **指望一次性爆红**：真正的增长是分波次的（单品 → 全仓 → 生态）
- **有产品无理论**：只有 skill 没有方法论，用户没有留下来的理由

## Key Takeaways
1. 好 skill 是"小、单用途、手动触发、鼓励改"
2. 检验价值的信号：fork/star 比、安装量/star 比、issues 活跃度
3. 作者 × 时机 × 人设 × 商业飞轮 四因叠加才成爆款
4. 生态分发（第三方清单）> 个人分发
