# Glossary — 术语表

**渐进式披露（Progressive Disclosure）** — 上下文按需加载，需要时才加载对应规范（Ch 2）

**库派（Library）** — skill 设计路线：小、单用途、手动触发、鼓励改（Ch 5）

**框架派（Framework）** — skill 设计路线：自动激活、硬性纪律、接管全流程（Ch 5）

**圈层型爆款** — 以分享密度为信号的真实需求型爆款，区别于流量型（Ch 4）

**商业飞轮** — 仓库作为课程漏斗免费入口，获客成本为零的流量顶端（Ch 4）

**信任储蓄** — 多年积累让作者的判断有分量（Ch 4）

**紧箍咒效应** — 规则从护栏变成限制：模型不是不会干，是不知道该听谁的（Ch 1）

**门槛（Gate）** — skill 的职能之一：在关键节点要求证据或验证（Ch 3）

**责任状（Charter）** — 强模型时代 skill 的定位：团队经验的责任状和门槛（Ch 2）

**上下文（Context）** — 模型进现场后能看到的真实情况：项目为何存在、过往决策、踩过的坑、验收标准（Ch 2）

**Prompt** — 单次指令，用完即焚，不复利（Ch 2）

**Thin harness, thick context** — 核心框架：轻驾驭、重上下文（Ch 2）

**分享密度** — 分享/阅读 比值，圈层型爆款的判断标准（Ch 4）

**触发问题（Trigger problem）** — skill 价值完全依赖触发时机；不触发 = 零收益（Ch 6）

**两周检验标准** — 装进流程两周后还在用的留下，积灰的删掉（Ch 7）
